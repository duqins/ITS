**AI use.**  The design in this document is our own work and follows on from our Phase 3 requirements. We chose the architecture, the entities and their relationships, the states, the access rules and the sustainability formulas ourselves. We used Claude (Anthropic) as an assistant: it helped us write up our notes into the sections, wrote the scripts that draw the ER, class and state diagrams from the entity and state definitions we gave it, and built the Word file from our Markdown files. We checked the result against the project description and the Phase 4 and 5 lab slides, and read the final document page by page. Each of us wrote and reviewed our own sections, committed them from our own GitHub account on our own branch, and a teammate reviewed every pull request before it was merged.
