# Introduction

This document shows how we will build Dawra Campus: the architecture (Phase 4) and the detailed design (Phase 5). It covers the whole system, every role, module and screen, and we will follow it when we build the prototype in Phase 6. People still make every approval decision, and every AI feature has a classic way to finish the same task.

We use the same IDs as our Phase 3 SRS: requirement IDs (FR, AI, NFR, SU and BR), screens UI-01 to UI-14, use cases UC-01 to UC-14, and the record state codes from SRS section 4.1 (AS, LS, RQ, RV, TR, MW, EL and AT).
