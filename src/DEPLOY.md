# Putting Dawra Campus online

The deployment follows the design (section 11): the Django app runs on Render and the data is in PostgreSQL on Neon. The AI calls go from the app to the Claude API. No key is ever stored in Git.

## 1. Database on Neon

The Neon project `dawra-campus` already exists in AWS Europe Central 1 (Frankfurt). Its `production` branch has the tables and the synthetic demo data. Sultan shares these privately (never in Git or the group chat):

1. The pooled connection string (its address contains `-pooler`). The app uses it for all normal traffic.
2. The direct connection string (no `-pooler`). The build uses it only to create tables, as Neon advises for migrations.
3. The password of the demo users in this database. It is not the local default.

## 2. App on Render

1. Sign in at https://render.com with GitHub and choose **New > Blueprint**.
2. Pick the `duqins/ITS` repository. Render reads `render.yaml` from the main branch and puts the app in Frankfurt, next to the database.
3. When Render asks for the values marked `sync: false`, enter:
   - `DATABASE_URL`: the pooled Neon connection string
   - `DATABASE_URL_UNPOOLED`: the direct Neon connection string
   - `ANTHROPIC_API_KEY`: the project key from the Claude Console (leave empty to run without AI)
   - `DEMO_PASSWORD`: the demo users' password from step 1 (only used if the database is ever empty)
4. Deploy. The build installs the packages, prepares the static files and creates any missing tables. The demo data is already there, so it is not added again.
5. Open the address Render gives (for example `https://dawra-campus.onrender.com`) and sign in as a demo user.

## Notes

- `SECRET_KEY` is generated by Render. `DEBUG` is off online.
- Render adds its own address to the allowed hosts automatically (`RENDER_EXTERNAL_HOSTNAME` in `dawra/settings.py`).
- On the free plan the app sleeps after some idle time; the first page after that takes about a minute.
- The Neon database also sleeps after 5 minutes without use and wakes on the next request. The app checks each saved connection before reusing it (`dawra/settings.py`).
- To change the AI key, edit `ANTHROPIC_API_KEY` in the Render service's Environment page and redeploy.
